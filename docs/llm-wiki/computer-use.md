## 架构

Grok Build ACP 注入会话 MCP `grok-computer-use` → loopback HTTP IPC（`127.0.0.1` + Bearer）→ Host Broker → 适配器。

- MCP 只是协议面，不持有桌面权限。
- 注入独立于 `official_aux_with_user_mcp`。
- YOLO / acceptEdits **不**授予桌面控制。
- 默认 `computer_use_enabled = false`。
- 定向目标失效直接拒绝，不回退全桌面。
- 同一桌面 exclusive lease；`stop_requested` ≠ `stopped`。
- 结果分 `applied` / `verified` / `rejected` / `unknown`。timeout → unknown，不自动重放。
- UI 预览与模型 `observe` 分开；隐藏预览停止周期采集。

## Agent 工具

模型 MCP：`computer_status` / `computer_list_targets` / `computer_open_target` / `computer_observe` / `computer_act` / `computer_wait` / `computer_request_handoff` / `computer_stop` / `computer_navigate` / `computer_download`。

authorize / resume / reconnect / pause、扩展配对和系统权限留在 Host/UI，不出现在模型工具面。

- `computer_act` 必须使用模型刚看到的 observation IDs；transport 成功不是 verified。
- `computer_wait` 也必须传 `version`、`actionId`、`runId`、`targetId`、
  `targetGeneration`、`snapshotId`、`geometryRevision`、`elementRef`、`nameEquals`；
  身份复制自 `computer_observe`，不由 Host 暗中补当前值。`timeoutMs` 可省略（默认
  2000 ms），指定时范围 1–10000，不能是 null。返回 `matched` 与 `outcome`；
  只有 verified 才 matched，超时是错误。它是 `computer_act(action=wait)` 的便捷
  入口而不是绕预算的 preview。此为未发布的实验工具 schema 变更，更新运行时后
  需重新建立会话 MCP catalog；不要兼容性降级为不带身份的旧请求。
- `unknown` 必须重新 observe；禁止用同一 actionId 重放副作用。
- `computer_stop` 只请求停止；模型不能 resume / reconnect / authorize。
- `computer_request_handoff` 不能自批。
- 截图以 image content 传递；无图不得坐标点击。
- 每步 observe → act → verify，连续动作复验 generation。动作/观察预算有界；in_flight 互斥，并行调用不能绕过。
- fork、压缩、会话恢复、换模型后必须重新授权/观察。Computer Use 不按动作新建聊天。
- 禁止操作 ChatGPT / 微信等用户未选窗口。只点用户授权的目标或自建 fixture。
- 剪贴板默认不读进观察。必须粘贴时只写入任务文本，并按序号 / 仍为我们写入的内容恢复用户剪贴板。
- 窗口 `target_id` 含 stamp；HWND 复用或宿主 `grok-app` 窗直接拒绝，不回退桌面。
- 授权窗口失去前台焦点时暂停，不派发前台输入；显示器拓扑 / DPI 变化使 geometry 失效，不回退桌面。
- 远程 IM、定时任务、SSH 会话不继承本机 Computer Use。
- 下载写入 run 所属 staging，不采用模型给的文件系统路径。
- WebView 未绑定 typed 目标时诚实 unavailable；禁止任意 eval，不从其他 App 面复用 cookie。

headless `grok -p` 调 MCP `use_tool` 会被权限提示取消。产品 UI 走用户批准；探针若必须 headless，只在**隔离 GROK_HOME** 的 argv 使用 `--always-approve`，不要打开用户全局 always-approve。

Grok CLI MCP stdout 必须是 NDJSON（JSON + 换行）。不要只发 Content-Length。

## 禁止

- 把浏览器或 XWayland 成功写成 Wayland native。
- 缺设备的行标 `passed`（用 `not_run`）。
- 默认打开 feature、默认 always-approve、改共享 `~/.grok`。
- 自动点系统权限框或用户的 ChatGPT/微信窗口。
- 占位按钮、假能力开关、豁免质量门禁。
