   字符串与 DateTime 的类型差异误判成 PID 复用。必要时交叉核 CIM 创建时间和 argv。
2. live 时只观察同一原 exec 句柄与增量日志、独立只读审查；不写 Grok 正在编辑的产品文件，

5. 通过后写下一份具名 dispatch，再用 launcher 派新唯一 runName、resume 原会话。
