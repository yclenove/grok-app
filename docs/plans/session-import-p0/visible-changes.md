# 用户能看见的导入改动（2026-09-08）

不是又一张「50 轮」表。打开应用会看到这些：

1. **导入向导 · 会话列表**  
   以前：后来发现的会话只显示一句「又发现了新会话」。  
   现在：这些 extra 会话出现在可勾选列表里，可以跟当前页一起导入。

2. **导入历史阅读器**  
   以前：只能往下看事件、点「在 Grok 中继续」。  
   现在：可以搜索这段导入、加载更多事件、把选中分支导出为 Markdown（复制到剪贴板）。

3. **侧栏「导入的历史」**  
   以前：没有导入时整组消失。  
   现在：始终显示，可搜索标题，空的时候有「导入会话与工作区」入口。

4. **设置 · 导入记录**  
   以前：只有一个打开向导的按钮。  
   现在：下面列出已导入记录，可打开阅读器或导出 Markdown。

5. **向导 · 点「预览」看会话正文**  
   以前：勾选后直接进映射，看不到内容。  
   现在：每条会话有预览按钮，下面列出前几条消息。

6. **阅读器 · 搜索结果可定位**  
   点搜索命中会滚到对应事件。

7. **侧栏每条导入**  
   可导出 Markdown，也可直接「在 Grok 中继续」（打开交接草稿）。

8. **向导 / 阅读器 / 侧栏有样式**  
   以前：步骤、勾选、预览、侧栏按钮挤成一排无样式控件。  
   现在：当前步骤有底线，选中的来源和会话有高亮，搜索命中事件有描边，侧栏每条导入是标题加操作行。

9. **阅读器能看出三类问题**  
   未知块、缺失图片、超大输出截断各自有说明，不再当成普通正文。

10. **系统文本只当字看**  
    来源里的 system 内容按纯文本显示，不会变成可点链接，也不会执行。

11. **导入结果页**  
    已提交的条目可以直接打开阅读器、导出 Markdown、在 Grok 中继续。阅读器标题用导入记录名；搜索按钮叫「搜索」。

12. **向导预览可加载更多**  
    以前：预览只显示前 20 条就停。  
    现在：下面有「加载更多」，左右方向键翻会话页。

13. **阅读器可从某条事件续聊**  
    消息行有「从这里继续」，交接草稿会标明覆盖范围、token 数和叶子。搜索命中也能再加载一页。

14. **会话列表看得出完整度和归档**  
    「选择当前结果」旁写明只用冻结快照；后来发现的 extra 要自己勾。侧栏导出成功会提示已复制。

15. **来源页可导入单个 JSON / Markdown 文件**  
    以前：只能选文件夹。  
    现在：有「导入 JSON 或 Markdown 文件」。目录在但不可读会标明仍可阅读历史。

16. **预览带库存和问题**  
    预览区显示完整/部分、事件数、消息/工具/附件数量，以及适配器报出的问题。会话行能看到来源路径。映射页显示根路径和主根。

17. **小窗口能滚动**  
    向导/阅读器在矮窗口里会缩事件列表、工具栏竖排。点搜索命中时，如果事件还没加载，会先翻页再滚过去。导入进行中显示「已完成 n / 总数」。

18. **向导步骤可点回去**  
    已经走过的步骤可以直接点。会话页能筛选、清空选择；上下方向键移动焦点，空格勾选，Enter 预览。

19. **侧栏可按来源筛**  
    Codex / Claude / Cursor / 文件 有按钮。搜索也会匹配来源名。标题旁带上来源。

20. **阅读器显示来源和日期**  
    标题下面有 provider、原生 id、导入日期。预览里能看到分支叶子。结果页导出成功会提示已复制。

21. **筛选后可全选 / 反选可见项**  
    「选择当前结果」仍是冻结快照。另有「选择可见项」「反选可见项」，只动当前筛选出来的行。筛空会提示没有符合的会话。扫描中有进度条。

22. **导入结果用会话标题**  
    以前：结果页是 candidateId / importId。  
    现在：尽量显示会话标题。每条会话可复制来源路径，不打开文件。

23. **侧栏可按新旧排序**  
    默认最新在前，可切到最旧在前。

24. **失败项看得到原因，结果页可点完成**  
    导入失败的行下面有错误说明。完成后有「完成」关掉向导。

25. **阅读器可按角色筛、复制正文、上下条命中**  
    用户 / 助手 / 全部。每条消息可复制纯文本。搜索命中可上一条 / 下一条。

26. **只看不完整 + 侧栏日期**  
    会话页可勾「只看不完整」。按 `/` 聚焦筛选框。侧栏每条带来导入日期。

27. **阅读器只看问题、n/p 翻命中**  
    「只看问题」筛未知块 / 缺图 / 截断。搜索命中可用 n / p。顶部显示已加载条数。预览消息可复制正文。

28. **映射页列出已选会话**  
    导入前能看见勾了哪些标题。撤销要再点一次「确认撤销」。会话列表有页码。设置里可直接导入文件。也可只看已归档。

29. **搜索命中有序号，筛空有提示**  
    当前命中显示「第 i / n 条」。角色/问题筛空会说明没有符合的事件。可复制当前可见正文，可跳到第一条问题。搜索可清除。

30. **重试也要确认**  
    失败重试和撤销一样，要点两次。勾选超过 20 条时映射页写「还有 n 条」。侧栏也能从文件导入。

源文件仍只读。`imp:` 不能当活会话发送。排除项不会进搜索/交接。
