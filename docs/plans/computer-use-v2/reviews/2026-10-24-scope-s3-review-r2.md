**Must fix — category (a) only**

1. **[P1; residual R1/R2, NOT a new class] Socket/catalog work can run after expiry without consulting authority.** `gcu-cli/src/scope/data.rs:109` selects `authority.changed()` against raw socket copying, but `gcu-core/src/scope/authority.rs:63` only waits for watch publication; it neither checks nor waits on the deadline. `gcu-mcp/src/server.rs:418` returns the catalog without connection-authority admission/publication checks.

   Schedule: establish a connection while Active; let the three-second deadline pass while withholding watcher polling; dispatch a new `tools/list` handler and poll the socket bridge. No tool/driver admission runs to call `expire`, so the catalog is served after expiry. This is a new request, not buffered output committed before expiry. The existing watcher-free test only calls desktop tools. Bind every handler, including catalog and early-return paths, and enforce the current authority/deadline at transport use. Add a bounded watcher-held-back socket/catalog test; also test the stale Busy branch returns fixed ScopeDenied rather than `busy`.

2. **[P1; NEW class] Failed script publication can disclose content through its error message.** `gcu-mcp/src/result.rs:152` passes an existing script error to `assemble_cleared`; `:408` substitutes ScopeDenied only when there is no error, while `:428` copies the retained message into both text and structured output. Script exceptions are untrusted content: `gcu-script/src/bindings.rs:149` captures their message, and `gcu-cli/src/script_worker.rs:330` converts the worker's error into `ToolError` without native-delivery provenance.

   Concrete schedule: under generation 1, a script reads an allowed state's text and throws `new Error("internal:" + state.text)`; its Finish frame reaches the parent; hold final encoding before its commit, then expire the lease (without polling the watcher), revoke, or rebind. `finish` rejects the producing epoch, but the fallback returns `internal` plus that text. No native delivery started, and this final error payload never passed the commit point. Even a content-free timeout produces a different refusal shape. This is a publication bypass through the error channel, not merely retention of an already committed artifact.

   Normalize authority-loss errors to fixed ScopeDenied → wire `app_denied`, retaining Stop priority. Preserve an unknown outcome only with trusted evidence that native delivery started; a script-chosen code/message is insufficient. Add a bounded finalization-barrier regression with a canary in the exception message, covering expiry/rebind/revoke and a forged `driver_error:` exception. Require no canary, state, images, files or alternate refusal message. The new test at `gcu-mcp/src/result_round5_tests.rs:282` supplies a supposedly native error directly; it does not prove that distinction and would miss this leak.
