**MERGE-AFTER-FIXES**

Independent static review of `86f92813` on `cu2/scope-s2`, one commit above `origin/feat/cu-v2`. Read ADR 0017 §§1–3/5, including S1/S3 residuals, core scope types/guard/wrapper, and the macOS diff and OS sinks. Paths below are relative to `computer-use/crates/`.

Seven category-(a) must-fixes follow. All belong to the supplied hunt categories; **no NEW class**. Rechecking freshly populated records is insufficient when they replace the admitted identity, combine different observations, or do not identify the actual receiver.

1. **[P1; categories 2/3/4] Delivery adopts a new identity instead of preserving admission.** `gcu-driver-macos/src/input/proof.rs:36`, `semantic.rs:88`; `gcu-core/src/scope/driver.rs:338`/`:351`.
   Schedule: core admits `(pid P, window W, incarnation 1)`; before `arm`, P closes W and creates an unregistered replacement reusing W; the table correctly advances to incarnation 2. `arm` calls this new binding `admitted`, and the post compares against incarnation 2, so input reaches the replacement. Core's later postcheck cannot undo it. Similarly, a reparented AX element gets its new window installed by `set_expected`. Carry the immutable binding admitted by core into each OS operation; never mint authority from a later lookup. Regression: change incarnation/window after core admission but before native preparation; assert zero posts/mutations.

2. **[P1; category 2] Cached AX tokens can authenticate a different CG window observation.** `gcu-driver-macos/src/scope_os/live.rs:63`/`:95`, `scope_os/evidence.rs:134`, `real/identity.rs:46`, `scope_os/table.rs:153`.
   Schedule: `prepare` publishes token T for W; W is destroyed and its id reused by another window of the same process before `windows()` reads CG rows. The new row is joined to old T solely by numeric id. Owner/start remain equal, so the table preserves the admitted incarnation and delivery passes. Retaining an AX proxy does not retain the remote NSWindow; the table mutex does not cover OS changes or token refresh. Prove continuity for the object actually used, refusing any unprovable gap; independently refreshed maps are not that proof. Regression: force reuse between token refresh and CG enumeration, without changing PID or reporting a dropped observation.

3. **[P1; categories 3/4] AX text append bypasses the new proof and still authorizes by geometry.** `gcu-driver-macos/src/text_input.rs:88`, `input/text.rs:196`/`:205`, `real/text.rs:164`/`:172`/`:65`.
   Schedule: admitted layer-0 A remains open; an unregistered floating text panel B in the same process has A's frame and owns focus. Call `TypeText` for A with `focus=None`. `RealText::focus` excludes B's nonzero CG layer and matches its AX frame to A; `append` repeats that match and writes B's `AXValue`. The armed CG gate never runs, and core only postchecks A. Pass the admitted binding through RealText and verify the focused element's exact SPI/window/incarnation at the AX write; refuse geometry-only alignment. Regression: this same-frame panel, plus movement to an unregistered window before append, must produce zero AX writes.

4. **[P1; category 4] HID keys admit unregistered key panels.** `gcu-driver-macos/src/scope_os/deliver.rs:53`, `scope_os/table.rs:202`, `scope_os/facts.rs:318`.
   Schedule: P is frontmost; admitted A is its foremost layer-0 window; unregistered floating/key panel B is above A. `front_app` skips B because its layer is nonzero, and keys do not run the coordinate hit test. Both PID and window checks pass while HID delivers to B. Verify the actual key/focused window with the same admitted binding, including panels/sheets, or refuse scoped HID. Regression: a nonzero-layer key panel above an otherwise valid A must receive no key-down.

5. **[P1; category 4] Activation is an ungated, process-wide OS sink.** `gcu-driver-macos/src/input/cg.rs:248`/`:257`, `input/mod.rs:217`/`:281`.
   Schedule: register only A while the same process also owns unregistered B; `Activate(A)` invokes `ActivateAllWindows`, affecting B. Its empty event plan never invokes `before_post`. Alternatively, reuse P after `arm` but before `runningApplicationWithProcessIdentifier`: the replacement process is activated without any start-time recheck. Gate activation against the original process/window evidence and use a confined operation; refuse it when only process-wide activation is available. Regression: A/B and PID replacement at activation must cause zero unauthorized activation calls.

6. **[P1; category 4] Successful checking still leaves global delivery unbound.** `gcu-driver-macos/src/input/cg.rs:195`/`:311`/`:320`; compare `real/reader.rs:114`/`:115`.
   Schedule: the last gate sees A frontmost and under the point, then execution pauses during CG construction/stamping; another application raises C under the point without physical input; execution resumes into HID `CGEventPost`, which routes to C. A can remain alive, so even core's postcheck need not fail. AX proof also precedes `act::prepare` and payload allocation in the same job; reparenting after proof can change the owning window. Build payloads first and put verification at the actual sink, but **disable any scoped route whose receiver cannot remain bound across check/use**, as ADR §2 requires. Regression: barriers after proof and before the final OS call, with focus/window ownership changed, must yield zero unauthorized delivery; reporting unknown afterward is insufficient.

7. **[P2; category 1] Boot-time fallback cannot prove boot identity.** `gcu-driver-macos/src/scope_os/live.rs:120`/`:128`.
   Collision schedule: UUID reads fail on boots B1 and B2; resetting/repeating the wall clock permits equal `kern.boottime`; repeated PID and process-start microseconds then produce an identical `ProcessInstance` for a replacement. A fresh driver's table can also restart W's incarnation at 1. Neither timestamp contains a boot-unique discriminator. Return `None` when the boot-session UUID cannot be proved, unless another OS source supplies equivalent uniqueness. Regression: unavailable UUID with readable boot time must refuse; replayed descriptors from distinct boots must not compare as admitted.

Nice-to-have / category (b):

- **Unscoped behavior changes:** `gcu-driver-macos/src/driver.rs:182` always installs enforcing evidence, including outside `ScopedDriver`. Disabling the private SPI now refuses ordinary live input/semantic actions. Portable tests use non-enforcing `closed()` and do not cover that regression. Make scoped enforcement explicit and add a live-adapter seam for the unscoped case.
- The live probe is correctly `#[ignore]` and checks `GCU_DESKTOP=1` before constructing the driver (`scope_os/tests.rs:668`). Its documented `--exact` command uses an unqualified name (`:664`), which can select zero tests; use the full test path or remove `--exact`.

Static positives: process start uses native-endian libc fields with size 136 / offsets 120 and 128 asserted, preserving microseconds; executable path is not an admission key; missing SPI closes the evidence APIs; the table has no eviction/reset-on-capacity path; cleanup uses independent, ungated `post_release`. Existing tests cover sequential table changes and scripted refusal/partial delivery, but not the schedules above. No source edits, Cargo, network, SSH, model, or desktop execution; this report is uncommitted.
